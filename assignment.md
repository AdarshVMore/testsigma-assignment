Backend Engineering Assignment
Thanks for interviewing with us. This assignment is meant to be short and open-ended — we're
less interested in a "finished product" and more interested in how you think through an
ambiguous problem and use AI coding tools to solve it.
The Assignment
Cross-Cutting Automation Concepts
1. 2. 3. Build a self-healing locator engine that can still find a web element even after its ID or class name
changes.
Reference: Testsigma / Testim (self-healing locators)
Build a visual regression tool that compares two screenshots and highlights the UI differences.
Reference: Applitools
Build a tool that turns raw test execution logs into a shareable pass/fail HTML report with
screenshots.
Reference: Allure Report
That's it — intentionally brief. Part of the exercise is deciding for yourself what "done" looks like
within the time you have.
What We Want You to Use
You're expected to use AI coding tools (Claude, ChatGPT, Cursor, Copilot, GitHub Copilot
Workspace, whatever you prefer) to build this. We're not testing whether you can write every
line yourself — we're testing whether you can:
-
-
-
-
Break a vague problem into the right smaller problems
Direct an AI tool with clear, specific prompts to get useful output
Recognize when the AI gets something wrong and course-correct
Make and justify your own technical decisions, rather than accepting defaults
What to Submit
Please submit all three of the following. All three matter — submissions missing the prompt log
or README will not be evaluated fairly, regardless of how good the code is.
1. Your code — as a zip, GitHub repo link, or similar.
2. 3. Your full prompt history — the actual chat log(s) with whatever AI tool(s) you used,
unedited. This is genuinely as important to us as the code itself, so don't skip it or tidy it
up.
A short README (half a page is plenty) covering:
-
What you understood the problem to be
-
What you chose to build, and what you deliberately left out — and why
-
Any assumptions you made
-
What you'd do next with more time
